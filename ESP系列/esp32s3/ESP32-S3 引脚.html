ESP启动后，你可以用这些引脚作为输入或输出。但要注意上拉/向下的电阻（见下文）。

如果你想用它们作为输入，确保开机时不要与默认配置冲突。

例如，在代码中连接一个按钮并使用该按钮是安全的。但如果你在启动时长按按钮，它会进入固件下载模式。

如果你想用它们作为输出，就要注意默认的上拉或下拉电阻。

I2S、I2C、SPI、UART、远程控制等......

这些设备可以使用ESP32-S3上的任何GPIO引脚。

你需要小心的别针

USB数据针脚

GPIO19、GPIO20——这两个都用于USB连接。

PSRAM

对于包含八进制PSRAM的模块（任何8MB PSRAM的模块），你绝对不能使用GPIO35、GPIO36或GPIO37。

JTAG引脚

GPIO39、GPIO40、GPIO41、GPIO42

这些引脚的行为由eFuse与GPIO3结合决定。默认情况下，如果你还没烧坏任何电子保险丝，这些针脚是安全的*。JTAG将通过USB提供。

如果你想用这些针脚做JTAG，必须烧一些eFuse，并在启动时控制GPIO3。完整详情请参见数据手册第2.6.4节。

*部分JTAG引脚在启动时开始拉起：

JTAG引脚 下载启动 SPI 启动（默认）
GPIO39 引体向上 引体向上*
GPIO40 引体向上 漂浮
GPIO41 漂浮 漂浮
GPIO42 漂浮 漂浮

GPIO39 在启动时启动。通过烧毁EFUSE_DIS_PAD_JTAG（又称HARD_DIS_JTAG）永久禁用JTAG引脚来解决这个问题。JTAG仍可通过USB端口使用。

GPIO39和GPIO40在“下载启动模式”中也会被调出——无论eFuse状态如何。

UART 引脚

GPIO43，GPIO44

这些默认是UART0，直到你的代码使用。它们都开启了上拉电阻。

ADC销钉

ADC信道都固定在引脚上，如果你用WiFi，就不能用ADC Unit 2

强化漏洞

以下的针在充能时会出现故障。

GPIO1、GPIO2、GPIO3、GPIO4、GPIO5、GPIO6、GPIO7、GPIO8、GPIO9、GPIO10、GPIO11、GPIO12、GPIO13、GPIO14、GPIO15、GPIO16、GPIO17：

  • 低级故障：引脚输出处于低电平状态，60微分。

GPIO18：

  • 低级故障：引脚输出处于低电平状态，60微分。
  • 高层故障：引脚在60微分的高电平输出状态下。

GPIO19，GPIO20：

  • 低级故障：引脚输出处于低电平状态，60微分。
  • 两个高级别故障：引脚在60微分的高水平输出状态下。

关于强化漏洞的更多信息

如果你在运行“你的”软件时看到某些引脚出现了 Power Up 故障， 但在运行简单的Hello World时则不然，这可能是常见的错误：

gpio_reset_pin(RELAY1_SC);
gpio_set_direction(RELAY1_SC, GPIO_MODE_OUTPUT);

该句法可见，例如：blink_example_main.c

相反，使用以下语法：

//zero-initialize the config structure.
gpio_config_t io_conf = {};
//disable interrupt
io_conf.intr_type = GPIO_INTR_DISABLE;
//set as output mode
io_conf.mode = GPIO_MODE_OUTPUT;
//bit mask of the pins that you want to set,e.g.GPIO18/19
io_conf.pin_bit_mask = (1ULL << RELAY1_SC);
//disable pull-down mode
io_conf.pull_down_en = 0;
//disable pull-up mode
io_conf.pull_up_en = 0;
//configure GPIO with the given settings
gpio_config(&io_conf);

该语法可在此找到，例如：gpio_example_main.c

关于强化漏洞的进一步考虑

在某些情况下，引脚默认连接到+3.3V或+1.8V的电源域。 例如GPIO20（D+）或GPIO48。

你可以在Bootloader的早期阶段关闭它们：

见此处

例如，以下代码：

void bootloader_before_init(void) {
    /* Keep in my mind that a lot of functions cannot be called from here
     * as system initialization has not been performed yet, including
     * BSS, SPI flash, or memory protection. */
    ESP_LOGI("HOOK", "This hook is called BEFORE bootloader initialization");
    gpio_hal_iomux_func_sel(GPIO_PIN_MUX_REG[GPIO_NUM_20], PIN_FUNC_GPIO);
    esp_rom_gpio_pad_select_gpio(GPIO_NUM_48);
    gpio_ll_output_enable (&GPIO, GPIO_NUM_48);
    gpio_ll_set_level (&GPIO, GPIO_NUM_48, 0);
}
