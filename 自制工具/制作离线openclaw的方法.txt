📦 构建 OpenClaw 离线包（ARM64）

1️⃣ 创建并进入容器

# 运行容器，挂载你的工作目录（假设为 D:\openclaw-offline）
docker run -it --platform linux/arm64 --network host --name openclaw-builder -v D:\openclaw-offline:/mnt/host arm64v8/ubuntu:22.04 bash
参数说明：
-it：交互式终端
--platform linux/arm64：强制使用 ARM64 架构
--name openclaw-builder：给容器命名
-v D:\openclaw-offline:/mnt/host：将 Windows 的 D:\openclaw-offline 目录挂载到容器的 /mnt/host，后续打包文件会自动出现在 Windows 的该目录下
执行后，你会进入容器的 bash 提示符（类似 root@...）。

2️⃣在容器内安装 Node.js 和 OpenClaw
依次执行以下命令（都在容器内运行）：
# 更新 apt 并安装必要工具
apt update && apt install -y curl tar xz-utils
# 安装 Node.js 24.x（ARM64 版本）
curl -fsSL https://deb.nodesource.com/setup_24.x | bash - && apt install -y nodejs

# 验证 Node.js 安装
node -v   # 应显示 v24.x
npm -v

# 创建工作目录
mkdir /opt/openclaw && cd /opt/openclaw

# 创建 package.json
cat > package.json <<EOF
{
  "name": "openclaw-offline",
  "dependencies": {
    "openclaw": "2026.3.8"
  }
}
EOF

# 配置一下 git 代理
git config --global url."https://ghproxy.com/https://github.com/".insteadOf "https://github.com/"

# 安装所有依赖（不执行安装脚本，仅下载）
npm install --ignore-scripts --offline --verbose

# 手动编译原生模块（针对 ARM64 编译 sharp、node-llama-cpp 等）
cd node_modules/sharp
npm run install --force
cd ../node-llama-cpp
npm run build --force
cd /opt/openclaw

# 打包整个 node_modules 到挂载目录
tar -czf /mnt/host/openclaw-full-offline-arm64.tar.gz node_modules package.json

# 退出容器
exit


3️⃣ 验证离线包
回到 Windows 的 PowerShell，查看 D:\openclaw-offline 目录，应该会看到 openclaw-full-offline-arm64.tar.gz 文件。这个文件就是你需要传输到麒麟 V10 机器的完整离线包。

4️⃣ （可选）清理容器
docker stop openclaw-builder
docker rm openclaw-builder

🚀 在麒麟 V10 上部署离线包
将 openclaw-full-offline-arm64.tar.gz 复制到麒麟机器（例如 /home/mzy/），然后执行：
# 解压
mkdir -p ~/openclaw && cd ~/openclaw
tar -xzf /path/to/openclaw-full-offline-arm64.tar.gz

# 创建全局软链接（让 openclaw 命令可用）
sudo ln -s ~/openclaw/node_modules/openclaw/openclaw.mjs /usr/local/bin/openclaw
# 或使用 .bin 目录的链接（如果存在）
sudo ln -s ~/openclaw/node_modules/.bin/openclaw /usr/local/bin/openclaw

# 验证安装
openclaw --version   # 应显示 2026.3.8

# 初始化配置（会生成 ~/.openclaw/openclaw.json）
openclaw onboard
💡 关键点提醒
ARM64 兼容性：我们在容器内编译了原生模块，确保它们能在麒麟机器上运行。
网络：容器内安装 Node.js 和 npm 包需要联网（通过宿主机网络），请确保你的 Windows 能正常访问外网。
文件传输：生成的 .tar.gz 文件可以直接用 U 盘或 scp 传到麒麟机器。
如果在容器内执行 npm install 时遇到网络问题，可以参照之前为 Docker 配置镜像加速器的方法，在容器内设置 npm 镜像源（例如 npm config set registry https://registry.npmmirror.com）。不过通常情况下，容器内会继承宿主机的网络配置。

步骤 2：将生成的离线包传输到麒麟机器
如果是在 Windows 上的 Docker 容器中构建，离线包会出现在你挂载的目录（例如 D:\openclaw-offline）。
将该 .tar.gz 文件通过 U 盘或 scp 等工具复制到你的麒麟 V10 机器上。
步骤 3：在麒麟 V10 上部署

💡创建全局软链接：

1️⃣ 查看容器状态
先确认容器是否存在以及是否在运行：
powershell
docker ps -a | findstr openclaw-builder
输出会显示容器的状态（Up 表示运行中，Exited 表示已停止）。

2️⃣ 如果容器已停止，先启动它
powershell
docker start openclaw-builder

3️⃣ 进入容器内部
powershell
docker exec -it openclaw-builder bash
-it：以交互模式打开终端。
bash：在容器内启动 bash shell。
执行后，你就会进入容器的命令行提示符（例如 root@a59f2febf301:/#），可以继续之前的操作（如安装依赖、编译等）。
如果你不确定容器是否在运行，也可以直接用 docker exec -it openclaw-builder bash 尝试，如果容器未运行会提示错误，再按步骤启动即可。



✅重新创建带挂载的容器
请在 Windows 的 PowerShell 中执行以下命令（不是容器内）：
# 如果之前有同名的容器，先删除它（可选）
docker rm -f openclaw-builder

# 创建并运行新容器，挂载 D:\openclaw-offline 到 /mnt/host
docker run -it --platform linux/arm64 --network host --name openclaw-builder -v D:\openclaw-offline:/mnt/host arm64v8/ubuntu:22.04 bash
执行后你会进入容器内的 bash，此时再执行 ls /mnt/host 应该就能看到你在 Windows 上存放的文件了。


关闭防火墙
netsh advfirewall set allprofiles state off













✅ 立即执行以下命令配置 Git 使用 HTTPS 替代 SSH

# 1. 设置全局替换规则：将 git@github.com: 开头的地址自动转为 https://github.com/
git config --global url."https://github.com/".insteadOf git@github.com:

# 2. （可选）同时替换 git:// 协议为 https://，以防有其他依赖使用
git config --global url."https://".insteadOf git://

# 3. 验证配置是否成功写入
git config --global --list | grep url
如果配置成功，你会看到类似这样的输出：
url.https://github.com/.insteadof=git@github.com:
url.https://.insteadof=git://
🔍 测试 HTTPS 克隆是否正常
# 尝试用 HTTPS 克隆那个顽固的仓库（应无需认证）
git clone https://github.com/whiskeysockets/libsignal-node.git
如果克隆成功，说明 HTTPS 协议可用，配置已生效。
如果克隆失败（如网络超时），可能是网络问题，请检查网络连接或更换网络环境。
🚀 重新运行 npm install
配置好 Git 后，清理之前的残留并重试：
rm -rf node_modules package-lock.json
npm cache clean --force
npm install --ignore-scripts













🚀 最终步骤（在容器内执行）
1️⃣  编译原生模块（针对 ARM64）
# 进入 sharp 模块目录并编译
cd node_modules/sharp && npm run install --force

# 进入 node-llama-cpp 模块目录并编译
cd ../node-llama-cpp && npm run build --force

# 返回项目根目录
cd /opt/openclaw

2️⃣ 打包完整的 node_modules
# 打包成 tar.gz 文件（注意检查挂载点）
tar -czf openclaw-full-offline-arm64.tar.gz node_modules package.json

3️⃣ 将打包文件导出到宿主机
你有两种方式将文件从容器中取出：

方式 A：通过已挂载的目录（推荐）
如果你启动容器时使用了 -v D:\openclaw-offline:/mnt/host，那么直接复制：

cp openclaw-full-offline-arm64.tar.gz /mnt/host/
之后在 Windows 的 D:\openclaw-offline 目录下就能找到该文件。

方式 B：使用 docker cp 命令（如果没有挂载）
在 Windows PowerShell 中执行（容器需要处于运行状态）：

powershell
docker cp openclaw-builder:/opt/openclaw/openclaw-full-offline-arm64.tar.gz D:\openclaw-offline\


📌 注意事项
编译 sharp 和 node-llama-cpp 可能需要一些时间，请耐心等待。

过程中如果出现权限错误，可以尝试在命令前加 sudo（但容器内默认是 root，通常不需要）。

npm 的警告和漏洞提示可以忽略，不影响离线包的使用。

✅ 完成后的验证
打包完成后，在 Windows 上确认文件存在，大小应该在几十 MB 到上百 MB 之间。这个文件就是你要传输到麒麟 V10 机器的完整离线包。

现在，你终于可以进入麒麟机器部署 OpenClaw 了！如果在最后这几步遇到任何问题，随时告诉我。
