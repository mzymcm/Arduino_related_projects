Tiny Core Linux 设置安装方法

1、下载镜像
https://mirrors.aliyun.com/tinycorelinux/ports.html

2、烧录镜像后修改 cmdline.txt
dwc_otg.fiq_fsm_mask=0xF dwc_otg.lpm_enable=0 console=tty1 console=serial0,115200 root=/dev/ram0 rootwait quiet nortc loglevel=3 noembed
dwc_otg.fiq_fsm_mask=0xF dwc_otg.lpm_enable=0 console=tty1 console=ttyAMA0,115200 root=/dev/ram0 rootwait quiet nortc loglevel=3 noembed
加入：
console=serial0,115200

3、如果使用I2C、SPI，可以修改 config.txt
# Uncomment some or all of these to enable the optional hardware interfaces
dtparam=i2c_arm=on
dtparam=i2s=on
dtparam=spi=on

enable_uart=1




默认情况下，串口控制台没有启动。把这句话加到/opt/bootlocal.sh

代码：[选择]
/sbin/getty -L ttyAMA0 115200 vt100

/sbin/getty -L ttyS0 115200 vt100 &

并做备份。无需编辑cmdline.txt

SPI 以太网
最便宜的方法之一是通过SPI总线连接以太网控制器。例如，这种控制器可以是ENC28J60，通常用于Arduino的以太网连接。最新的 Linux 内核在树莓派上有带有设备树覆盖层的驱动程序。例如参见 https://github.com/raspberrypi/linux/issues/795

该方案的优点是USB接口依然可用。缺点是该芯片（以及SPI的速度）仅支持10BASE-T（10 Mbps）以太网。


更好的ESP8266方案是把它作为SDIO设备连接到GPIO端口。
这价格便宜，而且通过WiFi能达到40Mb/s

http://oshlab.com/esp8266-raspberry-pi-gpio-wifi/

一点历史。ESP8266 IC（如果你没听说过）是一款非常受欢迎的WiFi微控制器，市场上有很多便宜的模块。它最初用作微控制器的UART串行接口，但后来被移植为通过LUA或Arduino作为独立微控制器运行。它是一款运行在80MHz频率的非常高速的微控制器。这是我最喜欢用来做项目的微控制器之一，因为它快速、便宜，而且支持WiFi。

该模块推出了几个版本，包括ESP-12E和ESP-12F（价格均约2-3美元），它们支持SDIO接口。这在很大程度上毫无意义，因为SDIO接口用于闪存。

然而，事实证明，这个ESP8266其实是ESP8089集成电路的重新品牌化。ESP8089是针对小型平板的SDIO无线芯片。如果你在启动时不像作为微控制器运行时那样拉下GPIO 15，它就以SDIO模式运行，基本上就是一块ESP8089集成电路。

该项目基于 Hackaday.io RPi WiFi 项目。我做了一些修改，以便在新Raspbian中支持新的Linux内核，并编写了一个脚本来完全自动化这个过程。要使用这个模块，你需要ESP-12E或ESP-12F模块。推荐使用ESP-12F。

首先，像这样接线ESP-12F。

ESP-12F					Raspberry pi
GND					GND
SCLK	---33欧姆电阻 --	SD_CLK/GPIO22
MOSI	---33欧姆电阻 --	SD_D1/GPIO25
GPIO10	---33欧姆电阻 --	SD_D3/GPIO27
GPIO9	---33欧姆电阻 --	SD_D2/GPIO26
MISO	---33欧姆电阻 --	SD_0/GPIO24
CS0		---33欧姆电阻 --	SD_CMD/GPIO23
CH_PD					SD_SD/GPIO0
VCC						3.3V

33欧姆电阻是实现SDIO所需速度所必需的，所以请不要遗漏它们。最好从5伏电源线拉线，ESP8266模块用独立的LDO线，但直接从3.3伏电源线拉Raspberry Pi应该没问题。

SSH进入你的树莓派，输入以下命令。你可能想先用 raspi-config 扩展文件系统。

cd ~
git clone https://github.com/oshlab/esp8089.git
cd esp8089
sudo sh install
这会花点时间。所以就坐着等，或者去喝杯咖啡吧。

完成后，重启你的树莓派。

sudo reboot
重启后，ESP8266模块应该会激活。你可以快速扫描一下，确认它是否正常工作。

sudo iwlist scan
它应该能扫描无线网络，并显示可用的网络。

现在它会像其他WIFI模块一样工作。干杯。
