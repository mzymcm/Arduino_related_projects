RTL8188FTV 无线网卡制作一个“通用安装包”

安卓手机 USB 网络共享 (USB Tethering)
这个方法最可靠，通过USB线直接为树莓派提供网络。
手机端设置：用USB数据线连接手机和树莓派后，在手机 设置 → 连接 / 网络和互联网 → 热点和网络共享 → 开启 USB网络共享。
树莓派端操作：在树莓派的终端里，执行sudo dhclient usb0命令，即可从手机获取IP地址。


🔑 核心方案：使用 DKMS 驱动源码
在开始前，如果您的树莓派尚未准备好编译环境，请先执行：
sudo apt update
sudo apt install git dkms raspberrypi-kernel-headers build-essential
关键点：务必安装 raspberrypi-kernel-headers 包，这是专门为树莓派内核准备的头文件，与通用 linux-headers-$(uname -r) 不同。
apt-get install linux-headers-$(uname -r)  这个不能用，用下面的方法
sudo apt install linux-headers-rpi-{v6，v7，v7l}
sudo apt install linux-headers-rpi-v6


📝 步骤一：准备源码与 DKMS 配置
从 GitHub 克隆驱动源码：
git clone https://github.com/kelebek333/rtl8188fu
cd rtl8188fu
创建 DKMS 所需的配置文件 dkms.conf，内容如下：
PACKAGE_NAME="rtl8188fu"
PACKAGE_VERSION="1.0"
MAKE[0]="'make' all"
BUILT_MODULE_NAME[0]="8188fu"
DEST_MODULE_LOCATION[0]="/kernel/drivers/net/wireless"
AUTOINSTALL="YES"
REMAKE_INITRD="YES"

//===========
AUTOINSTALL="YES"：确保内核更新后自动重编驱动。
REMAKE_INITRD="YES"：确保驱动在引导时就可用。

将源码复制到 DKMS 管理的源目录并注册：
sudo cp -r . /usr/src/rtl8188fu-1.0
sudo dkms add rtl8188fu/1.0
这条 add 命令很关键，它会检查 dkms.conf 并将驱动纳入 DKMS 管理。

📦 步骤二：打包成 .deb 安装包
在项目根目录下，创建 DEBIAN 控制文件夹：
mkdir -p DEBIAN
创建核心的控制文件 DEBIAN/control，内容如下：
Package: rtl8188fu-dkms
Version: 1.0
Architecture: all
Maintainer: Your Name <your.email@example.com>
Depends: dkms, raspberrypi-kernel-headers, build-essential
Description: DKMS source for Realtek RTL8188FTV WiFi driver
 This package provides the DKMS source for the Realtek RTL8188FTV USB WiFi adapter.
 It will automatically build the driver for your installed Raspberry Pi kernel.
将所有文件和配置打包成 .deb 包：

# 返回项目根目录
cd ..
# 执行打包命令
dpkg-deb --build rtl8188fu
成功后，当前目录下会生成名为 rtl8188fu.deb 的安装包。这个就是你需要的“通用安装包”。

📥 步骤三：在任何树莓派上安装
在其他任何树莓派上，只需两步即可完成安装：
将你制作好的 rtl8188fu.deb 文件传输到目标树莓派上。
在目标树莓派的终端中执行安装命令：
sudo dpkg -i rtl8188fu.deb
安装完成后，请务必重启树莓派，网卡就能被正常识别了。内核更新时，驱动也会由 DKMS 自动完成重建，无需用户干预。












# 1. 安装必要依赖和Git (如果之前没装)
sudo apt update

手动使用 DKMS 安装
如果你更想手动一步一步来，可以试试这个标准流程。

bash
# 1. 准备源码并清理 (确保在用户目录下)
cd ~
git clone https://github.com/kelebek333/rtl8188fu.git
cd rtl8188fu

# 2. 关键步骤：将源码添加到DKMS的源码目录
#    注意命令格式，不像你之前那样加 ./ 
sudo dkms add .      # 正确的添加方式

# 3. 编译和安装模块
sudo dkms build rtl8188fu/1.0
sudo dkms install rtl8188fu/1.0

# 4. 加载驱动模块
sudo modprobe rtl8188fu

# 5. 重启系统
sudo reboot
