使用 DietPi 自带软件仓库安装（最稳定）
这是官方论坛推荐的方式，可以避免很多兼容性问题 。请打开终端，输入以下命令打开 DietPi 的软件配置界面：
dietpi-software
搜索并选择软件：进入界面后，找到“Search for Software”选项，搜索 docker。你会在列表中看到 Docker 和 Docker Compose。
标记安装：使用空格键将这两项都选中 。
执行安装：按回车键确认，然后根据屏幕提示完成安装。DietPi 会自动处理依赖和配置。
配置用户权限（推荐）：安装完成后，建议将你的当前用户（通常是 dietpi）添加到 docker 组，这样执行 Docker 命令时就无需每次都加 sudo 了 ：
sudo usermod -aG docker $USER
重启生效：为了让用户组权限生效，请重启你的树莓派：
sudo reboot
重启后，可以通过 docker --version 和运行 docker run hello-world 来验证安装是否成功。

优化 DNS 解析（辅助手段）
# 备份原文件
cp /etc/resolv.conf /etc/resolv.conf.bak
# 编辑 resolv.conf
nano /etc/resolv.conf
将其内容替换为：
nameserver 223.5.5.5
nameserver 119.29.29.29
保存后立即生效，无需重启服务。


编辑主软件源文件：
nano /etc/apt/sources.list
将文件中原有的内容全部删除或注释掉（在行首加 #），然后根据你希望使用的镜像站，添加以下其中之一的内容：
中科大 (USTC) 源 
deb https://mirrors.ustc.edu.cn/raspbian/raspbian/ bookworm main contrib non-free non-free-firmware
# deb-src https://mirrors.ustc.edu.cn/raspbian/raspbian/ bookworm main contrib non-free non-free-firmware

编辑树莓派专用软件源文件：
nano /etc/apt/sources.list.d/raspi.list
同样，将原有内容替换为与上面对应的镜像站地址：
### deb https://archive.raspberrypi.com/debian trixie main
中科大的 raspi 源：
deb https://mirrors.ustc.edu.cn/raspberry-pi-os-images/raspios/ bookworm main
如果报错，还是用原来的吧。
deb https://archive.raspberrypi.com/debian trixie main






配置 Docker 国内镜像加速（推荐）
由于物理距离和网络环境，直接从 Docker Hub 拉取镜像经常超时。为 Docker 配置国内镜像源是最有效的解决方法。
# 创建或修改 Docker 守护进程配置文件
nano /etc/docker/daemon.json
在该文件中添加以下内容（使用中国镜像源）：
{
  "registry-mirrors": ["https://docker.1ms.run","https://docker.mhtsec.com"]
}

测试  /etc/docker/daemon.json 的格式正确性
python3 -m json.tool /etc/docker/daemon.json
验证镜像是否有效

docker pull hello-world
成功拉取了 hello-world 镜像，这表明 Docker 的基本功能正常，你配置的镜像加速器也在正常工作

常用配置和工具命令

#查看 Docker 版本
docker -v
sudo docker pull 仓库/镜像:版本（留空的话默认为 latest）
sudo docker run 加参数，用来创建容器
#查看运行容器
sudo docker ps
#查看所有下载的镜像
sudo docker images
#进入容器终端
sudo docker exec -i -t ha /bin/bash
#实时查看10行的 ha 日志
sudo docker logs -f -t --tail 10 ha
#重启 systemctl 守护进程
sudo systemctl daemon-reload
#设置 Docker 开机启动
sudo systemctl enable docker
#开启 Docker 服务
sudo systemctl start docker
 
#下载 Docker 图形化界面 portainer
sudo docker pull portainer/portainer
#创建 portainer 容器
sudo docker volume create portainer_data
#运行 portainer
sudo docker run -d -p 9000:9000 --name portainer --restart always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer
在图形化界面中操作更加便利。运行之后在浏览器中输入树莓派IP:9000 进入界面。
