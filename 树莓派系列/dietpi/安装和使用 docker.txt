使用 DietPi 自带软件仓库安装（最稳定）
这是官方论坛推荐的方式，可以避免很多兼容性问题 。请打开终端，输入以下命令打开 DietPi 的软件配置界面：
dietpi-software
搜索并选择软件：进入界面后，找到“Search for Software”选项，搜索 docker。你会在列表中看到 Docker 和 Docker Compose。
标记安装：使用空格键将这两项都选中 。
执行安装：按回车键确认，然后根据屏幕提示完成安装。DietPi 会自动处理依赖和配置。
配置用户权限（推荐）：安装完成后，建议将你的当前用户（通常是 dietpi）添加到 docker 组，这样执行 Docker 命令时就无需每次都加 sudo 了 ：
sudo usermod -aG docker $USER
重启生效：为了让用户组权限生效，请重启你的树莓派：
sudo reboot
重启后，可以通过 docker --version 和运行 docker run hello-world 来验证安装是否成功。

优化 DNS 解析（辅助手段）
# 备份原文件
cp /etc/resolv.conf /etc/resolv.conf.bak
# 编辑 resolv.conf
nano /etc/resolv.conf
将其内容替换为：
nameserver 223.5.5.5
nameserver 119.29.29.29
保存后立即生效，无需重启服务。


编辑主软件源文件：
nano /etc/apt/sources.list
将文件中原有的内容全部删除或注释掉（在行首加 #），然后根据你希望使用的镜像站，添加以下其中之一的内容：
中科大 (USTC) 源 
deb https://mirrors.ustc.edu.cn/raspbian/raspbian/ bookworm main contrib non-free non-free-firmware
# deb-src https://mirrors.ustc.edu.cn/raspbian/raspbian/ bookworm main contrib non-free non-free-firmware

编辑树莓派专用软件源文件：
nano /etc/apt/sources.list.d/raspi.list
同样，将原有内容替换为与上面对应的镜像站地址：
### deb https://archive.raspberrypi.com/debian trixie main
中科大的 raspi 源：
deb https://mirrors.ustc.edu.cn/raspberry-pi-os-images/raspios/ bookworm main
如果报错，还是用原来的吧。
deb https://archive.raspberrypi.com/debian trixie main






配置 Docker 国内镜像加速（推荐）
由于物理距离和网络环境，直接从 Docker Hub 拉取镜像经常超时。为 Docker 配置国内镜像源是最有效的解决方法。
# 创建或修改 Docker 守护进程配置文件
nano /etc/docker/daemon.json
在该文件中添加以下内容（使用中国镜像源）：
{
  "registry-mirrors": ["https://docker.1ms.run","https://docker.mhtsec.com"]
}

添加后的样子应该是以下例子的样子。

{
    "data-root": "/mnt/dietpi_userdata/docker-data",
    "log-driver": "journald",
    "log-level": "warn",
    "debug": false,
    "registry-mirrors": [
    "https://docker.1ms.run",
    "https://docker.mhtsec.com"]
}
保存文件后，重启 Docker 服务：
systemctl daemon-reload && sudo systemctl restart docker
重启后再次运行 docker run hello-world 测试。


测试  /etc/docker/daemon.json 的格式正确性
python3 -m json.tool /etc/docker/daemon.json
验证镜像是否有效
docker info | grep -A 5 "Registry Mirrors"
docker pull hello-world
成功拉取了 hello-world 镜像，这表明 Docker 的基本功能正常，你配置的镜像加速器也在正常工作
















安装 Portainer
创建专用存储卷
首先，我们要为 Portainer 创建一个“保险箱”（Docker 卷），用来长久保存它的所有设置和数据，这样即使容器出问题，配置也不会丢。
docker volume create portainer_data
运行 Portainer 容器
接下来，使用这条命令来启动 Portainer。它会自动从网上下载适合你树莓派（ARMv6架构）的镜像并运行。
请注意：如果你的树莓派是通过 Wi-Fi 连接的，运行 ifconfig 命令，找到 wlan0 或 eth0 下面的 inet 地址，记下它，下一步登录时会用到。
docker run -d \
  --name portainer \
  --restart=always \
  -p 8000:8000 -p 9443:443 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v portainer_data:/data \
  portainer/portainer-ce:latest


要使用 ，首先创建 Portainer 服务器用来存储其数据库的卷：docker run
docker volume create portainer_data
然后，下载并安装 Portainer 服务器容器：
docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:lts
默认情况下，Portainer 生成并使用自签名的 SSL 证书来保护端口 。或者，安装完成后，你也可以在安装时或通过 Portainer 界面提供自己的 SSL 证书。9443
如果你因遗留原因需要 HTTP 端口开放，请在命令中添加以下内容：9000docker run
-p 9000:9000
Portainer 服务器现已安装。您可以通过运行以下程序检查 Portainer 服务器容器是否已启动：docker ps
root@server:~# docker ps
CONTAINER ID   IMAGE                        COMMAND        CREATED         STATUS         PORTS                                                                                                NAMES
7963585688a9   portainer/portainer-ce:lts   "/portainer"   8 seconds ago   Up 8 seconds   0.0.0.0:8000->8000/tcp, [::]:8000->8000/tcp, 0.0.0.0:9443->9443/tcp, [::]:9443->9443/tcp, 9000/tcp   portainer
登录
安装完成后，您可以通过打开网页浏览器并访问以下网站登录您的 Portainer 服务器实例：
https://localhost:9443
如果需要，用相应的IP地址或FQDN替换，如果之前改过端口，请调整。localhost

你会看到Portainer服务器的初始设置页面。


简单解释一下：-p 9443:443 是把容器内的 443 端口映射到树莓派的 9443 端口，这样我们就可以通过 https:// 安全地访问管理界面了。

首次登录与设置
装好之后，就可以通过浏览器来初始化你的 Portainer 了。

访问界面
打开电脑或手机上的浏览器，在地址栏输入：https://你的树莓派IP地址:9443
例如：如果你的树莓派 IP 是 172.16.2.110，就输入 https://172.16.2.110:9443
注意：因为是第一次使用自签名证书，浏览器会提示“不安全”或“存在风险”，点击“高级”并选择“继续前往”即可。

创建管理员用户
首次访问会进入初始化页面，你需要为 admin 账户设置一个密码，务必牢记。

连接你的 Docker 环境
登录后，Portainer 会询问你要管理哪个 Docker 环境。选择 “Docker” 或 “Local”（本地），然后点击 “Connect” 或 “开始” 按钮。Portainer 会自动检测并连接到树莓派本地的 Docker 服务。

到这里，Portainer 就全部设置好了，你会进入它的主界面，可以开始愉快地管理容器了。
