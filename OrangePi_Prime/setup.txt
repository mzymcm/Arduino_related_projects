二、设置为中文显示

要把 XFCE4 桌面环境设置成中文，整个流程可以分成下面几步：

🛠️ 第一步：准备工作（更新软件源）
开始之前，先通过 SSH 连接到你的 Orange Pi Prime，然后刷新一下软件包列表：

bash
sudo apt update
🗣️ 第二步：安装中文语言包
这一步是让系统能显示和处理中文的基础。在终端里输入下面的命令来安装简体中文语言包：

bash
sudo apt install language-pack-zh-hans
说明：language-pack-zh-hans 是 Ubuntu 系统标准的中文语言支持包。安装好之后，你的系统就具备处理中文的能力了。

⚙️ 第三步：配置系统语言（Locale）
现在，我们把系统的默认语言设置成中文。

运行配置工具：

bash
sudo dpkg-reconfigure locales
用键盘的 上/下方向键 找到并选中 zh_CN.UTF-8 UTF-8，然后按 空格键 把它标记为选中状态（前面会出现一个 * 号）。

按 Tab 键将高亮条移动到 <Ok>，然后按 回车键 继续。

在接下来弹出的界面里，选择 zh_CN.UTF-8 作为系统的默认语言环境，按 回车键 确认。

最后，为了让语言环境变量立即生效，运行下面的命令：

bash
sudo update-locale LANG=zh_CN.UTF-8
这条命令会修改 /etc/default/locale 这个配置文件，让系统在下次启动时自动使用中文环境。

🔤 第四步：安装中文字体
为了让中文菜单和文字显示得清晰美观，需要安装一些专门的中文字体包。

bash
sudo apt install fonts-wqy-zenhei fonts-noto-cjk
说明：

fonts-wqy-zenhei：文泉驿正黑，是一款非常经典、开源的简体中文字体。

fonts-noto-cjk：Google 出品的 Noto 字体，覆盖了中日韩等多种文字，显示效果很棒。

🖥️ 第五步：重启并远程登录
完成上面的步骤后，重启系统让所有配置生效：

bash
sudo reboot
等系统重启后，再用你的远程桌面客户端（比如 Windows 自带的“远程桌面连接”）去连接你的 Orange Pi Prime。

✨ 第六步：登录后调整桌面显示（可选）
重启并登录到 XFCE4 桌面后，如果有些地方还是英文或者显示有问题，可以再检查一下：

在桌面空白处右键，选择 “Applications” > “Settings” > “Appearance”（外观）。

在打开的窗口里，切换到 “Fonts”（字体）选项卡。

确认默认字体被设置成了你刚刚安装的中文字体，比如 “文泉驿正黑” 或 “Noto Sans CJK SC”。这样就大功告成了！









第一步：安装中文语言包
首先需要安装完整的中文语言包。

bash
sudo apt update
sudo apt install language-pack-zh-hans
这个语言包包含了系统界面、菜单等翻译所需的所有文件。

第二步：配置系统默认语言环境
接下来，需要配置系统的语言环境（Locale）为中文。

方案一：直接编辑配置文件（推荐）

使用 nano 编辑器打开系统的 locale 配置文件：

bash
sudo nano /etc/default/locale
将文件中的内容替换为以下几行。这能让系统在Xfce、xrdp等各种环境下都优先显示中文。

bash
LANG="zh_CN.UTF-8"
LANGUAGE="zh_CN:zh"
LC_ALL="zh_CN.UTF-8"
按 Ctrl+X 键，然后按 Y 键，最后按回车键保存并退出。

方案二：使用配置工具（备选）
你也可以使用 dpkg-reconfigure locales 工具。

运行 sudo dpkg-reconfigure locales。

在列表中，用空格键选中 zh_CN.UTF-8 UTF-8，然后用 Tab 键切换到 <Ok> 并回车。

在下一个界面，将 zh_CN.UTF-8 选为默认语言，然后回车确认。

第三步：让环境变量生效
为了让当前终端会话和未来的xrdp会话都使用新的中文环境，执行以下命令：

bash
# 为当前会话设置临时环境变量
export LANG="zh_CN.UTF-8"
export LANGUAGE="zh_CN:zh"
export LC_ALL="zh_CN.UTF-8"

# 将中文环境写入用户配置文件，确保登录后生效
echo 'export LANG="zh_CN.UTF-8"' >> ~/.profile
echo 'export LANGUAGE="zh_CN:zh"' >> ~/.profile
echo 'export LC_ALL="zh_CN.UTF-8"' >> ~/.profile
第四步：重启xrdp服务并重新连接
现在重启xrdp服务，让所有修改生效。这是最关键的一步。

bash
sudo systemctl restart xrdp
完成后，请断开当前的远程桌面会话，然后重新连接一次。重新登录后，你会发现XFCE4的菜单、标题栏、设置窗口等都已经变成中文了。

为当前 root 用户添加强制参数（临时方案）
